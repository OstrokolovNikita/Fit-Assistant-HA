# Fit Assistant — Home Assistant
**v0.3.0 — экспериментальная версия.** Серверная интеграция для Huawei Watch Fit 4. Прямое HTTPS соединение через телефон, без дополнительного Android-приложения. Установка HAP v0.1 и сеть v0.2.1 подтверждены на часах; функционал v0.3 проверен на имитации окружения, не на реальном HA. Часовой клиент пока разрабатывается отдельно и не распространяется публично.

## Установка
В HA 2026.11+: Настройки → Marketplace → Add from link → https://github.com/OstrokolovNikita/Fit-Assistant-HA → Integration → Install. На более ранних версиях с HACS: Custom repositories → тот же URL → Integration → Download. Если запрошен перезапуск, перезапустить только Home Assistant.
## Настройка
Настройки → Устройства и службы → Добавить интеграцию → Fit Assistant. Создайте профиль часов, выберите датчики и отдельно разрешённые светильники/выключатели (до 20 объектов). Не выбирайте опасное оборудование. На часах с v0.3 нажмите «Подключить», в настройках профиля HA введите показанный восьмизначный код (10 минут), затем «Обновить» на часах. Доступ закрыт до одобрения. Для каждой пары часов отдельный профиль; можно отозвать доступ в настройках.
## Безопасность
HTTPS обязателен на внешнем маршруте. Отдельный случайный ключ часов, его хеш хранится в HA, ключ не является токеном HA. Не вводите пароль HA в приложение. Не отключайте авторизацию HA. Доступ только к явно выбранным объектам; команда только turn_on/turn_off для light/switch. Ключ на часах в локальном хранилище, не гарантированно аппаратно защищён. Подтверждайте только код с собственных часов. Не публикуйте URL частного сервера, ключи или профили подписи.
## Статус
Первый функциональный кандидат, не прошёл полевую проверку. Публичный репозиторий для установки по ссылке, не включён в общий каталог Marketplace. Лицензия на дальнейшее распространение пока не определена.
